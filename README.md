# rat keyboard
i made a keyboard with a cute little screen that can show rotating text, like "i love rats <3"

so this is my hackpad aka macropad with the little hackclub program, here you can see the guide  
https://hackpad.hackclub.com/

however i have done mine with onshape instead of fusion as i have a general dislike for fusion from when i tried making pcbs with it.

so this project was done with the assistance of ai in designing and things i didn't know, obviously though i modeled out the mount  also little note the exported files are stl, step files wont export
and made the pcbs myself with kicad, and the firmware is the same as the guide, its just qmk.

as for the components they are all given by hackclub for this so i will not list a vendor or price but here  is a simple table with the components and amount needed for this project:

| Component                 | Quantity |
| ------------------------- | -------- |
| MX style switches         | 4x       |
| Seeed XIAO RP2040         | 1x       |
| 1 EC11E Rotary encoder    | 1x       |
| 0.91 inch OLED display    | 1x       |
| white blank DSA keycaps   | 4x       |
| M3x16mm screws            | 5x       |
| M3x5mx4mm heatset inserts | 5x       |

but yeah so the build will of course need its pcbs, the pcbs fit the under the max size of the hackpad guide, so it should be cheap enough as just a two layer under 100x100 mm pcb, also the case should fit, when i made the case i decided id do the pcb with some extra money from me or sum to make it white and maybe maybe maybe ENIG, but yeah thats for me to get after i make this but yeah so i wanted a pretty pcb and to show it off so the case is a mount to hold it up and its just open to air, i personally like the ig exposed style, anyways here are pictures of the pcb.
